# Guition JC4827W543 HelloWorld

ESP-IDF v6 project for the **Guition JC4827W543** with ESP32-S3-WROOM-1
N4R8, 4 MB flash, 8 MB Octal-PSRAM and a 480x272 NV3041A display.

## Current State

- Drives the NV3041A over QSPI via the official `esp_lcd` framework and the
  shared `../components/esp_lcd_nv3041a` panel driver. Espressif does not
  publish an `espressif/esp_lcd_nv3041a` registry component.
- LVGL is wired up through `espressif/esp_lvgl_port`, which owns the LVGL task,
  tick and flush callback - no manual LVGL boilerplate in `main.cpp`.
- Uses LVGL v9 with one fullscreen draw buffer in PSRAM
  (`LV_COLOR_FORMAT_RGB565` + `swap_bytes=true`, equivalent to the former
  `LV_COLOR_FORMAT_RGB565_SWAPPED`).
- Backlight is driven by the ESP-IDF `ledc` PWM peripheral.
- Touch is intentionally not configured; this board/project has no touch.
- LovyanGFX is **not** used anymore; the local Arduino library is no longer
  pulled in.

The screen shows a small HelloWorld status UI with board name, display path and
uptime.

## Hardware Values

| Item | Value |
|---|---|
| Board | Guition JC4827W543 |
| MCU | ESP32-S3-WROOM-1 N4R8 |
| Flash | 4 MB, QIO @ 80 MHz |
| PSRAM | 8 MB Octal @ 80 MHz |
| Display | 4.3" 480x272, NV3041A |
| Display bus | QSPI (SPI3_HOST) via `esp_lcd` |
| Touch | none |

Display pinout and render-path notes are documented in
`../../BOARD_CODING_NOTES.md`.

## Project Layout

```text
HelloWorld/
├── CMakeLists.txt                 # vanilla ESP-IDF project file
├── README.md
├── sdkconfig.defaults             # Guition/ESP32-S3 defaults
└── main/
    ├── CMakeLists.txt             # app component requirements
    ├── idf_component.yml          # managed deps: lvgl, esp_lvgl_port
    └── main.cpp                   # esp_lcd + local NV3041A driver + UI
../components/
└── esp_lcd_nv3041a/               # shared esp_lcd panel driver for NV3041A QSPI
```

`sdkconfig` is generated from `sdkconfig.defaults`. If defaults change, remove
the generated `sdkconfig` and reconfigure.

## Dependencies

| Component | Source | Purpose |
|---|---|---|
| `lvgl/lvgl` | Espressif Component Registry | UI library |
| `esp_lcd_nv3041a` | Local project component | NV3041A QSPI panel driver |
| `espressif/esp_lvgl_port` | Espressif Component Registry | Glue between `esp_lcd` and LVGL |
| `esp_lcd`, `esp_driver_spi`, `esp_driver_ledc`, `esp_timer` | ESP-IDF built-in | Bus, panel framework, backlight PWM, tick |

`dependencies.lock` is generated by the ESP-IDF component manager on the next
reconfigure/build.

## Partition Table

The project uses a 4 MB no-OTA layout without NVS:

| Name | Offset | Size | Purpose |
|---|---:|---:|---|
| `phy_init` | `0xf000` | `0x1000` | RF PHY data |
| `factory` | `0x10000` | `0x300000` | single app slot, 3 MB |
| `storage` | `0x310000` | `0xf0000` | remaining flash for SPIFFS-style data |

The `0x9000..0xefff` area is intentionally unused for now. The app partition
still starts at `0x10000`, which keeps the normal ESP32 app alignment.

## Important Notes

- The default orientation mirrors the existing LovyanGFX `display.setRotation(2)`
  setup and is applied as `esp_lcd_panel_mirror(panel, false, false)` after init.
- Keep the 32 MHz QSPI pixel clock unless the panel has been retested.
- Keep fullscreen LVGL rendering in PSRAM for this NV3041A setup
  (`buff_spiram=true`, `buff_dma=false`).
- Do not copy RGB-panel, GT911 touch or calibration code from ESP32-8048S043C.
